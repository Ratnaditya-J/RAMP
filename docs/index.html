RAMP: Risk Accumulation and Monitoring Pipeline

RAMP is an open-source reference implementation for evaluating multi-signal safety classifiers under a common schema. It compares standalone guard models with accumulated evidence variants across prompt, embedding, activation, output, session, and tool/action signals.
